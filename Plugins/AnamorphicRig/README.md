# Anamorphic Rig

꺾인 LED 벽과 다중 패널 리그를 위한 언리얼 엔진 nDisplay 도구.

정해진 관람 위치(스위트스팟)에 선 사람의 눈에만 착시가 맞도록, 벽 형상에서
nDisplay 설정과 워프 메시를 만들고 영상을 미리 역왜곡한다. 코엑스 파도(SM타운 앞
전광판)와 같은 원리다.

**C++ 컴파일이 필요 없다.** 순수 파이썬 플러그인이라 블루프린트 전용 프로젝트에도
폴더째 넣으면 바로 동작한다.

---

## 요구 사항

| | |
|---|---|
| 언리얼 엔진 | 5.8 (5.4+ 에서도 동작할 가능성이 높지만 검증은 5.8 에서만) |
| 필요한 플러그인 | `PythonScriptPlugin`, `nDisplay` (둘 다 엔진 기본 제공) |
| 영상 변환 | `ffmpeg` 이 PATH 에 있어야 한다. 플러그인에 동봉하지 않는다 |

## 설치

1. 이 저장소를 프로젝트의 `Plugins/AnamorphicRig/` 로 복사한다.
   ```
   YourProject/
     Plugins/
       AnamorphicRig/
         AnamorphicRig.uplugin
         Content/Python/...
   ```
2. 에디터를 다시 시작한다.
3. 메뉴에 **Tools > Anamorphic Rig** 가 생긴다.

## 시작하기

1. 콘텐츠 브라우저 우클릭 > **Miscellaneous > Data Asset** > `AnamorphicRigSettings`
   를 만든다. 현장 하나가 에셋 하나다.
2. 에셋을 열고 치수를 넣는다. 값은 전부 **m** 단위로 받는다.
3. 에셋을 고른 상태에서 **Tools > Anamorphic Rig** 의 항목을 쓴다.

| 메뉴 | 하는 일 |
|---|---|
| 형상 점검 | 치수·화각·입사각·화소 밀도를 계산하고 위험하면 경고한다 |
| 평면도 보기 | 에디터 뷰포트에 평면도를 디버그 라인으로 그린다 |
| 벽 만들기 | 워프 메시와 nDisplay 리그를 현재 레벨에 만든다 |
| 클러스터 실행 | nDisplay 창을 별도 프로세스로 띄운다 |
| 영상 변환 (아나모픽) | 받은 영상을 벽 형상에 맞게 역왜곡한다. **납품용** |
| 영상 변환 (전개만) | 꺾임 보정 없이 비율만 맞춘다 (벽지용) |
| 눈 시점으로 되돌려 보기 | 벽 없이 착시가 맞는지 확인한다. 납품물이 아니다 |
| 무비 렌더 큐 점검 | 출력 해상도가 뷰포트와 맞는지 본다 |
| 렌더 결과 좌우 합치기 | `Saved/MovieRenders` 의 뷰포트 파일을 가로로 붙인다 |

## 벽 모델 두 가지

### 다중 패널 (`PanelChain`)

평평한 화면 N 장. 이음매마다 **꺾임각**으로 이어 붙인다. 패널마다 크기와 해상도가
달라도 되고, 떨어져 있는 화면도 좌표로 직접 놓을 수 있다.
nDisplay Screen 컴포넌트로 그대로 표현되므로 워프 메시가 필요 없다.

```
        vp_left        vp_right
      -16.05°..0°  |  0°..+22.93°
             ╲     |     ╱
              ╲    |    ╱
               ╲   |   ╱
                ╲  |  ╱
                 ● 스위트스팟
```

뷰포트들은 90도로 갈라지지 않는다. **붙어서 부채꼴 하나**를 만들고 각자 자기 각도
구간만 담당한다. 리그 정면보다 왼쪽에 아무것도 없으면 왼쪽 뷰포트는 절반이 아니라
완전히 빈다.

### 꺾인 벽 (`BentWall`)

한 장짜리 연속 벽이 코너에서 둥글게(필렛) 꺾인 형상. Screen 컴포넌트는 **항상 평면**
이라 이 형상을 표현할 수 없으므로, 전개 길이로 UV 를 매긴 **워프 메시**를 구워서
Screen 컴포넌트에 실어 보낸다. 좌우 면의 전개 길이가 달라도 된다.

```
        ←────── 전개 총길이 ──────→
   ╲                              ╱
    ╲        ●C                  ╱
     ╲   ╱‾‾‾‾‾╲                ╱
      ╲╱   필렛  ╲             ╱
       ╲__________╱
             │
             │ 관람 거리
             ●  스위트스팟
```

## 영상 세 가지

```
원본 ──(아나모픽)──→ _curved.mp4 ──[벽에 넣음]──→ 눈: 곧게 펴짐   착시 성립
  │
  └──(전개만)──────→ _wall.mp4   ──[벽에 넣음]──→ 눈: 코너에서 꺾임

        눈 시점으로 되돌려 보기 = 위 "눈:" 부분을 파일로 뽑는 시뮬레이터.
        벽에 넣는 파일이 아니라, 벽 없이 검증하는 용도다.
```

검증하는 법: 격자 영상을 아나모픽 변환한 뒤 되돌려 보면 **원본 격자와 똑같이 곧게**
나와야 한다. 대조군으로 전개만 맞춘 파일을 되돌리면 코너에서 확 꺾인다.

## 아는 함정

| 증상 | 원인 / 해결 |
|---|---|
| 창은 뜨는데 nDisplay 가 아니라 일반 카메라가 보임 | `-dc_dev_mono` 누락. 이게 없으면 렌더 디바이스가 아예 생성되지 않는다 |
| 창이 엉뚱한 모니터로 튐 / 크기가 안 맞음 | **작업표시줄 자동 숨김 필수**, 디스플레이 배율 100% |
| 해상도를 바꿨는데 무비 렌더 큐 결과가 그대로 | MRQ 는 `.ndisplay` 파일이 아니라 **레벨 DCRA 에 구워진 값**을 쓴다. '벽 만들기' 를 한 번 돌리면 반영된다 |
| 패널 이름/개수를 바꿨는데 반영이 안 됨 | nDisplay 임포트는 기존 에셋을 덮어쓰지 못한다. 콘텐츠 브라우저에서 에셋을 지우고 다시 빌드할 것 |
| 벽이 통째로 까맣게 나옴 | 영상 경로 확인, 또는 백페이스 컬링 (`면 뒤집기` 를 켠다) |
| 재빌드가 조용히 실패 | 다른 에디터가 그 레벨을 열고 있음 |
| 좌상단 빨간 글씨 | nDisplay 를 켜면 늘 나오는 엔진 경고. `디버그 오버레이 숨김` 으로 끈다 (진짜 경고도 같이 사라진다) |

## 구조

```
Content/Python/
  init_unreal.py          진입점. 에디터 시작 시 메뉴 등록
  anamorphic_rig/
    geometry.py           형상 코어. PanelChain / BentWall       (unreal 불필요)
    report.py             점검 리포트와 경고                      (unreal 불필요)
    config.py             .ndisplay 생성 + 클러스터 실행 인자      (unreal 불필요)
    video.py              ffmpeg 영상 변환                        (unreal 불필요)
    settings.py           uclass/ustruct. 디테일 패널 자동 생성
    build.py              워프 메시, DCRA, 뷰포트 Region, 영상 플레이트
    preview.py            평면도 디버그 드로잉
    menu.py               메뉴 배선
```

`geometry` / `report` / `config` / `video` 는 언리얼에 의존하지 않는다. 일반 파이썬으로
import 해서 오프라인 계산이나 테스트에 쓸 수 있다.

```
python -c "import geometry; geometry.demo()"    # 형상 자체 점검
python -c "import config; config.demo()"        # 설정 생성 자체 점검
```

## 아직 안 되는 것

- **멀티 노드 클러스터.** 지금은 `node_0` 하나만 쓴다. 노드가 2개 이상이면 명시적으로
  에러를 낸다. LED 프로세서 입력이 여러 개로 쪼개지는 현장은 아직 지원하지 않는다.
- **면마다 높이가 다른 꺾인 벽.** 전개면이 직사각형이 아니게 되면 영상 파일 구조와
  안전 밴드 계산이 달라진다. 좌우 *길이* 가 다른 것은 지원한다.
- **커스텀 위젯 UI.** 설정은 디테일 패널로 표시된다.
